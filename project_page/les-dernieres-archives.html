LES DERNIÈRES ARCHIVES

These pieces comprise four printed documents. I question how we inhabit the world when the image loses its function as proof of reality. Inspired by Rosa Menkman, Shintaro Miyazaki's text "Counter-Dancing Digitality," and Hito Steyerl. The glitch is like a counter-algorithmic approach. The first edition is my opinion on how collapse is a tool for critique. The second edition focuses on how human subjectivity disappears in the context of artificial intelligence images. The third edition addresses the glitch as resistance. The fourth edition is a diary set in the future, featuring the glitch.
